🛠️ ConfAdmin — index.json kiosque

Générateur de data/index.json pour une instance MyKTAMap auto-hébergée (plans pré-installés sur le serveur).

🔒 Tout se passe dans ce navigateur — aucun fichier n'est envoyé nulle part. Les ZIPs sont lus localement pour en extraire les métadonnées ; le résultat est un fichier index.json à télécharger puis déposer toi-même sur ton serveur.

📦 1. Plans du kiosque

Dépose les ZIPs générés par MyKTAMap (Générateur ou export). L'outil lit le plan-config.json de chacun pour pré-remplir id / nom / version / badges. L'id devient le nom du dossier sur le serveur (data/<id>/) — modifiable, minuscules sans espace.

🌀 2. Liaisons inter-plan (portails)

Récupère tes liaisons depuis le profil de ce navigateur (ouvre cette page depuis ton instance MyKTAMap — même adresse — sinon le profil est introuvable) ou depuis un export de profil (.json). Ensuite, fais correspondre chaque plan d'origine à un plan du kiosque : les ids locaux sont remappés vers les ids serveur.

⚙️ 3. Réglages kiosque

⚠️ Ces réglages sont du désencombrement d'interface, pas un verrou de sécurité. Sous-titre, flags et liaisons sont lus depuis v1.73.0 — un index.json qui les contient reste valide sur toutes les versions (champs inconnus ignorés). Guide complet : docs/applications/SELFHOST.md.

📤 4. index.json

{ "plans": [] }

Déploiement :

  1. Décompresse chaque ZIP dans data/<id>/ (le dossier doit contenir plan-config.json à sa racine).
  2. Dépose ce fichier en data/index.json.
  3. Sers le site en statique (aucun backend) — les plans apparaissent dans « 📚 Mes plans » avec le badge 🌐.
  4. Hors-ligne : chaque plan doit avoir été ouvert une fois en ligne pour être disponible offline.
