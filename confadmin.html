🛠️ ConfAdmin — index.json kiosque

Générateur de data/index.json pour une instance MyKTAMap auto-hébergée (plans pré-installés sur le serveur).

🔒 Tout se passe dans ce navigateur — aucun fichier n'est envoyé nulle part. Les ZIPs sont lus localement pour en extraire les métadonnées ; le résultat est un fichier index.json à télécharger puis déposer toi-même sur ton serveur.

📦 1. Plans du kiosque

Dépose les ZIPs générés par MyKTAMap (Générateur ou export). L'outil lit le plan-config.json de chacun pour pré-remplir id / nom / version / badges. L'id identifie le plan (minuscules sans espace). Format : 📦 ZIP (recommandé) — le ZIP est servi tel quel (data/plan.zip), téléchargé à l'ouverture et gardé sur l'appareil pour le hors-ligne ; 📂 Dossier — le ZIP décompressé dans data/<id>/.

⚙️ 3. Réglages kiosque

🔌 Connexion serveur — réservé aux instances qui greffent des modules de connexion Laisse sur « désactivée » pour un kiosque : rien n'est écrit dans index.json, et l'app affiche « Base de données : désactivée ». « Activée » ne charge rien tant qu'une licence pro n'est pas posée sur l'instance et qu'aucun module n'est installé ; l'état est toujours affiché aux visiteurs. Contrat : docs/architecture/community-server-line.md §3.

⚠️ Ces réglages sont du désencombrement d'interface, pas un verrou de sécurité. Sous-titre, flags et liaisons sont lus depuis v1.73.0 — un index.json qui les contient reste valide sur toutes les versions (champs inconnus ignorés). Guide complet : docs/applications/SELFHOST.md.

📤 4. index.json

{ "plans": [] }

Déploiement :

  1. 📦 Plan ZIP : dépose le fichier au chemin indiqué (ex. data/plan.zip), sans le décompresser. 📂 Plan Dossier : décompresse le ZIP dans data/<id>/ (plan-config.json à sa racine).
  2. Dépose ce fichier en data/index.json.
  3. Sers le site en statique (aucun backend) — les plans apparaissent dans « 📚 Mes plans » avec le badge 🌐.
  4. Hors-ligne : un plan ZIP ouvert une fois est gardé sur l'appareil (selon le réglage « Mémoriser ») ; un plan Dossier se télécharge par le bouton ⬇️ de sa ligne.
