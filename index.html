📖 Que fait l'app sur le réseau ?
MyKTAMap est une PWA 100% client-side. Tout ce que tu crées (annotations, sessions, plans mémorisés, calibrations KMZ, préférences) reste dans ton navigateur. Le serveur Nginx ne fait que servir des fichiers statiques. Aucun backend applicatif, aucune base de données serveur, aucun analytics, aucun cookie de tracking.

🔍 Comment vérifier toi-même
  1. Journal interne : bouton « 📋 Voir le journal réseau » dans la même section — logue en temps réel toutes les requêtes émises par l'app.
  2. DevTools navigateur (F12) : onglet « Network » / « Réseau » → tu vois toutes les requêtes, indépendamment de ce que l'app raconte. Filtre par méthode pour vérifier qu'il n'y a aucun POST/PUT/PATCH/DELETE.
  3. Mode hors-ligne strict : coche le toggle dans la même section. Le navigateur refusera activement toute requête non-whitelistée — l'app reste 100% fonctionnelle.
  4. Content Security Policy : F12 → Network → première requête (HTML) → onglet Headers → cherche Content-Security-Policy. Le serveur Nginx demande au navigateur de bloquer toute connexion non whitelistée (connect-src 'self' https://www.gstatic.com).
